# Use-Case-03

| UC-03 | Description |
| --- | --- |
| Name | Consult General Information and External Referral |
| Principal Actor | Newly enrolled student / Student |
| Description | The system provides in-person service details of School Control (hours, location, and contacts) or directs the user to the corresponding department when an inquiry falls outside the area's scope, using option selections or natural language text input. |
| Preconditions | The virtual assistant chat window is open and ready for interaction. |
| Postconditions | The chat interface displays service details, contact cards, or external department referral information. |
| Requirements Covered | [FR-002](../Requirements/FR/FR-002.md) <br> [FR-005](../Requirements/FR/FR-005.md) <br> [FR-004](../Requirements/FR/FR-004.md) <br> [FR-006](../Requirements/FR/FR-006.md) |

## Main Flow

1. The user reviews the interface options and text input box in the open chat window.
2. The user clicks the service window option bubble or types a query regarding operational details.
3. The system displays information regarding in-person window hours and direct contact details (institutional email and phone)
4. The system asks if the user requires assistance with any other inquiry.


## Alternative Flows

>AF-01: Detailed attention or resolution failure
1. In step 3, the user indicates that the provided information does not resolve their specific problem and requests to speak with administrative staff.
2. The interface highlights direct phone numbers and emails of School Control staff for personalized attention.

## Exceptions

>EX-01: Out-of-scope inquiry referral
1. In step 2, the user types a question or selects an option about a process outside the scope of School Control (e.g., IMSS, scholarships, or languages).
2. The system identifies that the request does not correspond to School Control.
3. The screen displays referral information clearly indicating the responsible department.
4. The information provides alternative contact details (emails, phone numbers, and office locations) of the corresponding department staff to immediately redirect the student.
