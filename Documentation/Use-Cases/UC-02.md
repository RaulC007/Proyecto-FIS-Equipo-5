# Use-Case-02

| UC-02 | Description |
| --- | --- |
| Name | Consult New Student Enrollment Guide and Academic Terms |
| Principal Actor | Newly Enrolled Students |
| Description | The system provides guidance regarding enrollment document submission, deadlines, and the explanation of school management terms requested by the user through the chat interface via option bubbles or text input. |
| Preconditions | The virtual assistant chat window is open and ready for interaction. |
| Postconditions | The chat interface renders the requested enrollment guidelines, deadlines, or academic term definitions. |
| Requirements Covered | [FR-001](../Requirements/FR/FR-001.md) <br> [FR-002](../Requirements/FR/FR-002.md) <br> [FR-003](../Requirements/FR/FR-003.md) <br> [FR-006](../Requirements/FR/FR-006.md) <br> [FR-007](../Requirements/FR/FR-007.md) |

## Main Flow

1. The user reviews the interface options and text input box in the open chat window.
2. The user clicks the enrollment document option bubble or types a query regarding enrollment document submission.
3. The interface displays the required document checklist, in-person delivery procedure, and application deadlines set by the faculty.
4. The user clicks the academic glossary option bubble or types a query requesting clarification on an academic term.
5. The interface displays a clear and concise explanation of the requested concepts.
6. The chat asks whether the response resolved the user's inquiry.

## Alternative Flows

>AF-01: Service window hours inquiry
1. In step 3, the user inquires about the service hours of School Control to deliver documents.
2. The bot displays the operational hours within the faculty.

## Exceptions

>EX-01: High school certificate delay
1. In step 2, the user states that their previous high school has not yet issued their official certificate and asks how to proceed.
2. The interface notifies that in such cases, they must present a completed studies certificate (constancia de estudios concluidos) issued by their origin institution.
3. The interface specifies the deadline by which the student must physically visit School Control to deliver the official certificate.
