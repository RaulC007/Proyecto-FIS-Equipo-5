# Use-Case-01

| UC-01 | Description |
| --- | --- |
| Name | Consult and Initiate Academic Certificate Procedure |
| Principal Actor | Newly enrolled student |
| Description | The user interacts with the virtual assistant interface either by clicking predefined FAQ option bubbles or by typing queries into the text input box to display structured instructions, fees, and requirements directly in the chat window. |
| Preconditions | The virtual assistant chat window is open over the main portal interface. |
| Postconditions | The chat interface displays the structured procedure details and direct links corresponding to the user's selection or input. |
| Requirements Covered | [FR-001](../Requirements/FR/FR-001.md) <br> [FR-002](../Requirements/FR/FR-002.md) <br> [FR-004](../Requirements/FR/FR-004.md) <br> [FR-006](../Requirements/FR/FR-006.md) |

## Main Flow

1. The user reviews the welcome greeting, scope banner, and interactive FAQ option bubbles displayed in the open chat window.
2. The user clicks an option bubble corresponding to certificate guidance or types a custom query into the text input box.
3. The system processes the selection and displays structured information regarding available certificate types, specific requirements, current fees, and accepted payment methods.
4. The user interacts with action buttons or links provided within the response to access external forms or templates.
5. The assistant asks the user if their query has been resolved.


## Alternative Flows

>AF-01: Request or pick up through a third party
1. In step 2, the user clicks the option bubble related to third-party authorization or types a query asking if a family member or third party can request or pick up their document.
2. The interface displays instructions indicating that the web request can be made by a third party, but in-person pickup strictly requires a simple power of attorney (carta poder simple) and official identifications.

## Exceptions

>EX-01: Special format certificate request
1. In step 3, the user requests a non-standard certificate format (e.g., specific weighted averages or custom breakdowns for external scholarships). 
2. The interface detects the special condition and displays a warning banner indicating that non-standard certificate formats must be evaluated and authorized directly by the Academic Secretary, complying with visual certificate management guidelines.
3. The interface provides the direct institutional contact details (email and office location) for the Academic Secretary.
4. The use case ends without generating standard application links.
