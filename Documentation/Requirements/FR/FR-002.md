# Functional-Requirement-002
>>Priority and Justification: High, It is the core component of the main screen (Home), necessary to the conversational interaction and structured response delivery before guiding the user to secondary sections.

## Requirement Name
Conversational Chat.

## Requirement Description
The system must provide a conversational interface that processes user queries in natural language and responds using structured text (numbered steps, bullet points, or short lists).

## Acceptance Criteria
Given a user submitting a query via the chat input, when the bot generates a response, then it formats multi-step instructions into bullet points or numbered lists with a maximum limit of 50 words per point and a response time of 5.0 seconds or less under normal conditions.
