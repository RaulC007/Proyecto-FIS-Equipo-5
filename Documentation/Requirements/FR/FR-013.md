# Functional-Requirement-013
>Priority and Justification: High

## Requirement Name
Request and Delivery of Certificates by Third Parties

## Acceptance criteria


## Requirement Description
The system must inform users that a third party can request a certificate by completing the online form, and indicate that a letter of authorization will be required for the in-person delivery of the document.
