# Functional-Requirement-004
>Priority and Justification: High, It prevents confusion and unnecessary in-person visits for non-standard requests.

## Requirement Name
Visual Management of Certificates and Special Format.

## Requirement Description
The system must provide the details and costs for each type of certificate, as well as the Academic Secretary's contact details and instructions for requesting special formats.

## Acceptance Criteria
 Given a user consulting certificate verification options, when selecting a specific document type, then the system displays fee values, accepted payment methods, and contact details for the Academic Secretary without missing any information.
