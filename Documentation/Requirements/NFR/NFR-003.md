# Non-Functional-Requirement-003
>Priority and Justification: High, Students make decisions based on official procedure data, so incorrect answers could cause errors, delays, or rejected procedures.

## Requirement Name
Reliability - Information Accuracy and Reliability 

## Requirement Description
The system must provide accurate information based strictly on the official School Control database/knowledge base, avoiding the generation of false information (hallucinations).

## Acceptance Criteria
The chatbot must achieve a 95% accuracy rate in a test set of 50 frequently asked questions, validated by School Control staff.
