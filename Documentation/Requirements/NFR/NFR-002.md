# Non-Functional-Requirement-002
>Priority and Justification: High, It allows costs, schedules, and requirements to be updated without modifying the system, keeping the information current without affecting the core functionality.

## Requirement Name
Maintainability - Information Maintenance.

## Requirement Description
The system must allow procedure information to be updated when requirements, costs, lead times, or schedules change, without modifying other system functions.

## Acceptance Criteria
Given an administrator updating a procedure's fee or required documents in the data repository, when the changes are saved, then the updated information is reflected in the system interface within 20 minutes without causing downtime or affecting other modules.
