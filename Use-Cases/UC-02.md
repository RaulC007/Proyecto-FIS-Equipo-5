# Use-Case-02

| UC-02 | Description |
| --- | --- |
| Name | Consult required documents for enrollment |
| Principal Actor | Newly Enrolled Students |
| Description | The system provides information about the enrollment document delivery guide, specifies the procedure and deadlines, and resolves doubts regarding school management terms requested by the user. |
| Preconditions | The user has the chat interface active and is ready to type text. |
| Postconditions | The interface displays the document guide, deadlines, and the definition of the consulted term. |
| Requirements Covered | [FR-001](../Requirements/FR/FR-001.md) <br> [FR-002](../Requirements/FR/FR-002.md) <br> [FR-003](../Requirements/FR/FR-003.md) <br> [FR-006](../Requirements/FR/FR-006.md) <br> [FR-008](../Requirements/FR/FR-008.md) <br> [FR-009](../Requirements/FR/FR-009.md) |

## Main Flow

1. The student types a query about the delivery of enrollment documents
2. The interface displays the information, which contains:
    - List of required documents
    - In-person delivery procedure.
    - Deadlines for the period set by the faculty.
3. The student types requesting clarification about an academic term
4. The interface displays a clear and concise explanation of the consulted concepts.
5. The chat asks whether the answer resolved the doubt.

## Alternative Flows
>AF-01: Inquiry about office hours
1. In step 2, the student asks what office hours the School Control office is open to bring the documents.
2. The bot displays the service hours and the location within the faculty.

## Exceptions
>EX-01: Delay in the issuance of the high school certificate
1. In step 1, the student writes stating that their home high school has not yet issued their official certificate and asks how to proceed.
2. The interface notifies that for these cases, they must present a certificate of completed studies issued by their home institution.
3. The interface indicates the specific deadline on which the student must go in person to the School Control office to deliver the official certificate.
