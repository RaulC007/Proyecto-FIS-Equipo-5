# Use-Case-01

| UC-01 | Description |
| --- | --- |
| Name | Consult and start the academic record process |
| Principal Actor | Newly Enrolled Students |
| Description | The system processes the user's natural language query regarding the process for obtaining academic records and displays structured information on the interface, covering types, requirements, costs, and delivery times, while providing a direct link and action buttons to initiate the online request. |
| Preconditions | The user has the chat interface active and is ready to type text. |
| Postconditions | The interface displays the structured information for the procedure and the interactive button to copy or open the direct link. |
| Requirements Covered | [FR-001](../Requirements/FR/FR-001.md) <br> [FR-002](../Requirements/FR/FR-002.md) <br> [FR-005](../Requirements/FR/FR-005.md) <br> [FR-010](../Requirements/FR/FR-010.md) <br> [FR-011](../Requirements/FR/FR-011.md) <br> [FR-012](../Requirements/FR/FR-012.md) <br> [FR-013](../Requirements/FR/FR-013.md) <br> [FR-014](../Requirements/FR/FR-014.md)  |

## Main Flow

1. The user asks about the certificates in the text box
2. The interface displays a structured response with the catalog of standard certificates and their specific requirements, current costs, payment method, and estimated delivery time
3. The user types a message requesting access to the procedure
4. The interface displays a message with the link to request the certificate
5. The chat asks whether the inquiry was resolved

## Alternative Flows
>AF-01 Request by a third party or delivery to a third party
1. In step 1 or 3, the user types asking whether a family member can request or pick up their document.
2. The interface displays instructions stating that the web request can be made by a third party, but for in-person delivery, a simple power of attorney letter and identifications are mandatory.
3. The screen includes a button to download the power of attorney template.

## Exceptions
>EX-01: Request for a certificate with a special format
1. In step 1, the user types requesting a non-standard format (e.g., specific weighted averages or a special breakdown for an external scholarship).
2. The interface detects the special condition and displays a notice stating that non-standard certificates must be evaluated and authorized directly by the Academic Secretary.
3. The screen shows the Academic Secretary's institutional contact information (email and office).
4. The use case ends without sending the standard link.
