# Use-Case-03

| UC-03 | Description |
| --- | --- |
| Name | Consult General Information and External Referral |
| Principal Actor | Students |
| Description | The system provides the in-person service details for School Control (hours, location, and contacts) or refers the user to the corresponding department when the procedure does not belong to the area. |
| Preconditions | The user has the chat interface active and is ready to type text. |
| Postconditions | The interface displays the guide of the guide of documents, deadlines, and the definition of the consulted term |
| Requirements Covered | [FR-002](../Requirements/FR/FR-002.md) <br> [FR-003](../Requirements/FR/FR-004.md) <br> [FR-006](../Requirements/FR/FR-006.md) <br> [FR-007](../Requirements/FR/FR-007.md) |

## Main Flow

1. The user inquires about the service details of the counters
2. The system displays the following information:
3. In-person service hours at the counter
4. Direct contact methods (institutional email and phone).
5. Location of the counters within the faculty.

## Alternative Flows
>AF-01: Resolution failure or request for detailed attention to their request.
1. In step 3, the user states that the information provided does not resolve their particular problem and that they need to speak with administrative staff.
2. The interface highlights the direct phone numbers and emails of the School Control counter staff for personalized attention.

## Exceptions
>EX-01: Inquiry about a procedure outside School Control / Referral
1. In step 1, the user asks a question about a process outside the scope of School Control
2. The system identifies that the procedure does not correspond to the School Control department.
3. The screen displays referral information clearly indicating the responsible department
4. The information provides alternative contacts (emails, phone numbers, and location) of the staff of the corresponding area to redirect the student immediately.
